# Placeholder fixtures

Every PNG in this directory is **PLACEHOLDER_NOT_SHIP**.

They are solid-color, locally generated 512x512 RGBA stand-ins used only to
exercise `assets/manifest.json`, `scripts/asset_validate.py` and renderer
plumbing. They are not generated or final art. Do not present them as finished
visuals. Replace them with reviewed original layers and update the manifest
hashes before release.

The species files are simple ellipses placed inside the canonical safe region.
The item file is a simple rectangle near the `head` anchor. All files are
intentionally named with the `PLACEHOLDER_` prefix so they cannot be mistaken
for shippable assets.
